# SRP Prototype

Sales Revenue Projections frontend prototype built with React 19, Vite, and Tailwind CSS v4.

## Stack

- React 19
- Vite
- Tailwind CSS v4
- IBM Plex Mono (monospace numerics)

## Getting Started

```bash
npm install
npm run dev
```

Runs on `http://localhost:5174` by default.

## Features

- Positions table with multi-select (shift-click range selection)
- Scenario filtering (All / Pessimistic / Realistic / Optimistic)
- Bulk action toolbar (Extend, Copy/Move, Clone, Delete)
- Full-screen modals for each bulk action
- Scope bar (account + year)
- Project filter with tag pills
